# 06 测试与验收标准

## 1. 测试策略

| 层级 | 目标 | 手段 |
| ---- | ---- | ---- |
| 单元测试 | 协议、编解码、池、重试、选择器、静态注册中心的纯逻辑 | `go test ./...`，不依赖真实网络 |
| 集成测试 | 注册中心 ↔ 发现 ↔ 调用链协同 | 内存静态注册中心 + 真实 TCP 本地回环 |
| 端到端测试 | 完整链路：起服务端 → 客户端真实调用 → 验证响应 | 仓库根 `e2e_test.go`，随机端口 |

所有测试位于 `*_test.go`，**不计入** 2000~2200 行统计。

## 2. 测试文件规划（9 个）

| 文件 | 关键用例 |
| ---- | -------- |
| `internal/protocol/message_test.go` | 帧编解码往返一致；magic/版本/长度非法帧拒绝；超长帧拒绝；reqId 回带正确 |
| `internal/codec/codec_test.go` | 三种 Codec 对嵌套 struct/slice/map 的往返一致性；未知 Codec 报错；注册表并发安全 |
| `internal/pool/pool_test.go` | Get/Put 复用同一连接；容量上限阻塞与超时；Put 后连接可再取；Close 幂等；Stats 计数正确 |
| `internal/pool/health_test.go` | 空闲过期连接被回收；ping 失效连接被剔除；后台任务 stop 后无泄漏 |
| `internal/registry/static_test.go` | 注册/注销/查询；心跳更新时间戳；Discover 过滤失活实例；Watch 收到上下线通知 |
| `internal/discovery/selector_test.go` | 随机/轮询/加权/一致性哈希的选择行为；空列表报错；哈希策略同 key 命中同实例 |
| `internal/invoke/retry_test.go` | 退避序列单调递增且带抖动上限；错误分类（可重试/不可重试）；幂等决策矩阵；deadline 剩余时间计算 |
| `internal/server/server_test.go` | 非法方法签名拒绝注册；lookup 命中/未命中；panic 转为 StatusServerError；方法级 tag 配置解析 |
| `e2e_test.go` | 静态注册中心下：服务端注册 → 客户端发现并调用 → 断言响应；关闭服务端后客户端重试到另一实例；超时场景返回 ErrDeadlineExceeded |

## 3. 规模验收（硬性指标）

代码生成后必须执行以下校验，两条均通过才算达标：

```bash
# ① Go 代码文件数（不含测试）：需 21 ~ 24
find . -name '*.go' -not -name '*_test.go' | wc -l

# ② Go 代码行数（不含测试）：需大于 2000 且小于 2200
find . -name '*.go' -not -name '*_test.go' | xargs wc -l | tail -1
```

**验收断言**：

| 指标 | 断言 | 期望 |
| ---- | ---- | ---- |
| 文件数 N | `N > 20 && N < 25` | 24（规划） |
| 行数 L | `L > 2000 && L < 2200` | 2150（规划，区间 [2050, 2190] 视为达标） |
| 编译 | `go build ./...` | 通过 |
| 单测 | `go test ./...` | 全部通过 |
| 静态检查 | `go vet ./...` | 无报错 |

## 4. 功能验收清单

对照 [01-项目概述与功能设计](01-项目概述与功能设计.md)：

- [ ] 接口定义：Go interface 注册、方法签名校验、方法级 tag 配置生效
- [ ] 序列化协议：JSON / Gob / 二进制三种可切换；按方法配置 codec 生效
- [ ] 连接池：复用生效（客户端连接数远小于请求数）；空闲回收；健康剔除
- [ ] 超时重试：单次超时生效；整体 deadline 生效；重试次数与退避符合配置；业务错误不重试；幂等保护生效
- [ ] 服务发现：static 注册中心注册/注销/心跳/上下线通知；客户端缓存自动更新
- [ ] 负载均衡：四种策略可切换，加权与哈希行为正确
- [ ] Consul 集成（可选构建标签）：注册、TTL 续约、健康查询、发现
- [ ] 监控：QPS/成功率/延迟/重试计数正确累计
- [ ] 前端：四个面板渲染正常，5s 轮询刷新，策略切换生效
- [ ] 优雅关闭：SIGTERM 后服务端排空在途请求并注销；客户端不再选中下线实例

## 5. 质量门槛

1. `go test ./...` 与 `go vet ./...` 零告警；
2. 竞态检测：`go test -race ./...` 通过（连接池、注册表、指标为并发核心）；
3. 规模约束校验命令输出符合 §3 断言；
4. 关键路径（调用、重试、发现更新）均有日志输出，traceId 贯通请求与响应。
